Seletor de Atributo

Serve para selecionar elementos HTML com base nos seus atributos sem precisar criar clases ou IDs. Exemplo:

input[type="email"] {
border: 2px solid blue; }

Resultado: apenas o campo de e-mail recebe a borda azul.

Seletor Descendente

Serve para selecionar elementos HTML que estejam dentro de outro elemento. Exemplo:

div p {
color: blue; }

Resultado: o texto da tag "p" que está dentro de "div" fica azul.

Seletor Filho Direto

É utilizado para selecionar apenas os filhos diretos de outro elemento HTML. Exemplo:

div > p {
color: blue; }

Resultado: se as tags "p" e "section" estão dentro de "div", apenas "p" (filho direto) fica azul.

Seletor Adjacente Direto

É utilizado para selecionar um elemento que aparece imadiatamente depois de outro elemento. Exemplo:

elemento1 + elemento2 {
color: blue; }

Resultado: apenas "elemento2" fica azul.

Seletor de Irmãos Gerais

É utilizado para selecionar todos os elementos que vêm depois de outro elemento desde que ambos sejam irmãos. Exemplo:

elemento1 ~ elemento2 {
color: blue; }

Resultado: todos os elementos do tipo "elemento2" que aparecem depois do elemento1 e que compartilham o mesmo pai ficam azuis.

Seletor de Pseudoclasse

É utilizado para, por exemplo, mudar a cor de um botão diante de determinada situação, como quando o mouse passa sobre ele. Exemplo:

button:hover {
background-color: blue; color: white; }

Seletor de Pseudoelemento

É utilizado para, por exemplo, mudar a cor apenas da primeira letra de um parágrafo, estilizar a primeira linha de um texto... Exemplo:

p::first-letter {
color: red; font-size: 30px; }

Resultado: a primeira letra do parágrafo fica vermelha e maior.
